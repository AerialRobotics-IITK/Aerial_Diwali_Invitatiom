# Aerial Robotics Diwali Invitation

Responsive React + Vite invitation site for Team Aerial Robotics, IIT Kanpur.

## Run locally
- Install Node.js 18 or newer.
- Run `npm install`.
- Run `npm run dev` and open the local URL printed by Vite.

## Production
Run `npm run build`; deploy the generated `dist/` folder to Vercel, Netlify, or another static host.

## QR image
`public/phonepe-qr.png` is the uploaded PhonePe QR image copied unchanged. Keep it as-is to preserve scan reliability.

The countdown targets 8 November 2026, 8:00 PM IST. Optional sound is off by default and generates a simple original bell-like sequence in-browser.
